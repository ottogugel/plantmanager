# 🌱 PlantManager

Aplicativo mobile desenvolvido com **React Native + Expo**, inspirado no projeto **PlantManager** da [Rocketseat](https://www.rocketseat.com.br/).

O objetivo é auxiliar no gerenciamento e acompanhamento dos cuidados com plantas.

## 🚀 Tecnologias

* React Native
* Expo
* TypeScript
* Expo Router
* NativeWind
* AsyncStorage

## ✨ Funcionalidades

* 🌱 Listagem de plantas
* 🪴 Visualização dos detalhes
* 💧 Informações sobre cuidados
* 📱 Interface mobile responsiva
* 💾 Armazenamento local

## 🎨 Layout

Projeto baseado no design disponível no Figma:

[PlantManager — Figma](https://www.figma.com/design/0mIGtTaSU8EHxEOrTwoiWd/PlantManager--Copy-)

## ▶️ Executando o projeto

```bash
npm install
npx expo start
```

Depois, abra o projeto pelo **Expo Go** ou em um emulador Android/iOS.
